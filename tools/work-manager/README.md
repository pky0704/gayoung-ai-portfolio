# 작업 관리 화면 소스 백업

현재 작업 화면과 독립형 앱의 소스를 보존한 사본입니다. 기존 포트폴리오의 `/admin`과 아직 통합되지 않았으며 운영 배포본이 아닙니다.

검색 버튼, 사이트/프롬프트 탭, 작업 등록·수정·보관, 우측 썸네일 링크와 사이트 열기 버튼, 이미지·QR 기능이 포함됩니다.

공개 저장소용으로 개인 작업 목록, 관리자 이메일, 실제 썸네일 파일, 인증정보는 제외했습니다. `seed/works.json`은 빈 목록입니다. 원본 작업 자료는 별도 보관합니다.

## 로컬 확인
Node.js 24에서 이 폴더로 이동한 후 실행합니다.

```sh
npm ci
npm run prepare-ui
npm test
npm run build
```

`preview.html`은 생성 후 브라우저로 열 수 있습니다. 로그인 보호가 없고 변경 사항은 해당 브라우저에만 저장됩니다.

## 연결 상태
이 독립형 앱은 NextAuth Google 로그인과 Postgres를 사용합니다. 실제 로그인과 DB 연결은 아직 검증되지 않았습니다. `.env.example`은 빈 설정값만 포함합니다. 운영하려면 서버 환경에서 Google OAuth, AUTH_SECRET, AUTH_URL, ADMIN_EMAIL, DATABASE_URL을 설정해야 합니다. Google 계정의 검증된 이메일이 ADMIN_EMAIL과 정확히 일치해야 합니다.

DB 설정은 `npm run db:setup`으로 수행합니다. 기존 ID를 덮어쓰지 않습니다. 실제 서비스 전에는 로그인·타 계정 거절·데이터 저장 및 이미지 접근을 검증해야 합니다.

기존 포트폴리오 관리자는 Supabase를 사용하므로, 후속 통합에서는 기존 인증과 데이터 구조에 맞추는 작업이 필요합니다. 이 폴더를 추가하는 것만으로 기존 관리자 화면이 변경되지는 않습니다.

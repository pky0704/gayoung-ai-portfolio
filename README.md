# 가영이네 AI 장사기록

박가영의 외식업 현장 AI 프로젝트 포트폴리오. Next.js App Router 기반이며 Vercel 배포와 Supabase 관리 기능을 준비했습니다.

## 실행

```bash
npm ci
npm run dev
```

## 구성

- `/`: 밝은 갤러리형 포트폴리오. 디자인 커버 바로 아래 실제 화면 캡처.
- `/projects/[slug]`: 프로젝트별 제작 배경, 사용법, 구현 범위.
- `/admin`: 구글 로그인 및 관리자 전용 등록·수정·미리보기·공개 상태·순서·휴지통·복구·JSON 내보내기.
- 캡처 확대: 브라우저 기본 dialog, Esc 닫기, 포커스 복귀.
- 서버에서 Google 로그인 사용자 UUID를 검증한 뒤에만 관리 API 실행.
- Supabase 미설정 시 최초 5개 공개 사례만 표시하며 관리자 로그인은 잠금 상태.
- Supabase 연결 후에는 DB가 유일한 콘텐츠 기준. DB 장애 시 이전 샘플을 몰래 표시하지 않음.

## 개발 상태

첫 구현입니다. 기존 A안 프로토타입 원본은 확보되지 않아 승인된 PRD의 A안 요구사항을 기준으로 구현했습니다.
실제 사이트 화면은 브라우저에서 직접 캡처했습니다. 음성 레시피는 로그인 화면만 확인했습니다.

배포 주소, Google OAuth, 실제 데이터 저장·복구·이미지 업로드의 운영 검증은 계정 설정 후 완료해야 합니다. 로컬 빌드 성공은 운영 서비스 연결 완료를 의미하지 않습니다.

## 설치와 배포

[운영 연결 안내](docs/SETUP.md)를 참고하세요. 코드와 공개 캡처만 Git에 저장합니다. 인증키와 관리자 식별자는 비공개 환경변수로 설정합니다.

## 이미지

`public/covers/`는 타이포그래피 커버입니다. `public/captures/`는 실제 서비스의 대표 화면 캡처입니다. 생성 이미지로 서비스 화면을 대체하지 않았습니다.
최초 공개 사례의 캡처는 공개 Git 저장소에도 포함됩니다. 관리자에서 새로 올린 이미지는 비공개 Supabase Storage에 저장하고 서명 URL로 표시합니다.

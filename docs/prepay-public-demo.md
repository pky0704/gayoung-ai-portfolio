# 선결제 발표용 체험 연결

2026-10-12: 공개 카드·상세 페이지에서
https://gayoungene-prepay.vercel.app/demo.html 로 연결한다.

- 체험판은 실제 접수·장부 저장·알림·결제를 수행하지 않는다.
- 기존 DB에 운영 URL이 남아 있어도 공개 카탈로그에서 체험 URL로 치환한다.
- 숨김 여부와 관리자 저장 데이터는 보존한다.
- 실제 운영 사례 설명은 유지하고, 공개 버튼은 체험판임을 표시한다.
- npm test 14개, TypeScript 검사, 프로덕션 빌드 통과.
- 선결제 저장소 main의 b004d52 커밋이 체험판 구현이다.
- 체험판 배포 응답과 배포된 app.js가 테스트 소스와 일치함을 확인했다.
- DOM 환경에서 개인/부서 신청→확인→체험 완료와 네트워크 요청 0회를 확인했다.
- 실제 브라우저의 모바일 레이아웃 검증은 이번 환경에서 수행하지 못했다.
- Vercel 관리 API의 팀 범위 403과 GitHub 자동 배포 상태는 별개로 확인한다.

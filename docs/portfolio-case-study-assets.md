파일 기준 경로: `public/case-study/`.

각 프로젝트의 `desktop.webp`는 공개 사이트 첫 화면, `feature.webp`는 실제 화면을 가독성에 맞게 발췌한 이미지입니다. 모바일 목업은 실제 사이트 임베드입니다. 외부 사이트가 임베드를 막도록 변경되면 실제 모바일 캡처로 교체합니다.

- 메뉴: Tteokbokki 샘플 상세. 가격·사진·재료의 검수 상태는 사이트 안내를 따릅니다.
- 브랜드: 브랜드 가이드 준비 안내. 실제 이미지 제작은 개인 AI에서 진행합니다.
- 경쟁 분석: 준비된 가영이네 사례의 실행 계획 탭. 실시간 분석·매출 성과가 아닙니다.
- 음성 레시피: 공개 로그인 화면만 확인. 계정을 입력하지 않았습니다.
- 리뷰: 옛날떡볶이 + 매콤달콤해요를 선택한 기능 확인용 가상 초안. 리뷰를 게시하지 않았습니다.

출처 링크는 각 상세페이지 하단에도 표시합니다. Behance 참고작의 UI나 이미지를 콘텐츠 자산으로 복제하지 않았습니다.

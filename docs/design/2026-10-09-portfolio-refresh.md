# 포트폴리오 디자인·문구 개편

사용자가 승인한 2026-10-09 수정안에 따라 홈은 전체 프로젝트 탐색, /ai-school은 교육 참여·발표에 집중한다.

- 홈: 짧은 자기소개 다음 전체 프로젝트. 데스크톱 3열, 모바일 1열. 카드의 이미지·태그·제목·설명·버튼 위치 통일.
- 오렌지·화이트·크림은 개인 포트폴리오에 사용. 민트는 홈의 작은 교육 태그와 전용 발표 페이지에 제한. 민트 배경/오렌지 버튼 조합 금지.
- 교육 태그는 기존 제작 기록으로 확인된 참여 기간 작업을 뜻하며 공식 과제·협업을 의미하지 않는다.
- /ai-school: 참여 목적, 확인된 일정(8/27 첫 수업, 10/10 발표 예정), 주요 6개 사례, 실제 사용 경험, 향후 계획. 미확인 일정·수치 공란.
- 제목은 기능 이름, 설명은 사용자 행동을 우선. 프롬프트는 AI에 복사해 넣는 요청문으로 설명.
- 이전 시안과 초기 캡처는 상세에서 유지하되 초기 기록이라는 안내를 가까이 표시한다.
- 현재 데이터·관리자 기능·외부 사이트는 변경하지 않는다. 콘텐츠 표시는 기존 데이터 위에 명시적인 편집 문구를 적용한다.
- 검수: 빌드, 타입 검사, 기존 테스트, 홈/발표/모든 상세 URL, 모바일 가로 넘침, 카드 정렬, 필터·목차 링크.
- 배포: 확인된 pky0704/gayoung-ai-portfolio main에 일반 push. 배포 성공은 별도 확인하며 접근 차단 시 구분해 보고한다.

## 검수 결과
- Next.js production build와 TypeScript 검사 통과.
- 기존 데이터 검증 테스트 4개 통과.
- Chromium: 1440px·390px·320px에서 홈, 교육 페이지, 상세 10개(36개 조합) HTTP 200, 가로 넘침 없음, pageerror 없음.
- 전체 10개 / 교육 참여 기간 9개 / 제작 중 3개 필터 확인.
- 홈·교육 페이지 PC/모바일 캡처 시각 검토. 교육 화면의 헤더/푸터 포인트도 민트로 분리.
- Safari 및 실물 휴대폰 검수는 이 작업에서 수행하지 않음.

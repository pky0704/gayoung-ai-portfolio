# 작업 관리 / 운영 관리자 통합

## 구현 범위
기존 `/admin`의 Supabase Google 로그인과 서버 관리자 UUID 검사를 재사용한다. 로그인 후 기본 화면은 작업 모아보기이며 기존 포트폴리오 게시 관리로 전환할 수 있다.

사이트/프롬프트, 검색 버튼, 개발 단계, 사용 여부, 작성 날짜, 관리자 주소, 비공개 메모, 이미지 업로드, QR 생성·다운로드, 포스터, 보관·복구, JSON 내보내기를 지원한다. 썸네일은 카드 오른쪽에 배치하고 사이트 링크와 하단 사이트 열기 버튼을 제공한다. 작은 화면은 세로 배치한다.

공개된 포트폴리오만 최초 목록으로 가져온다. 작업 관리에서 수정한 정보와 프롬프트는 별도 `work_items` 테이블에 저장하며 포트폴리오 게시 상태를 변경하지 않는다. 날짜와 개발 단계는 추측하지 않는다.

## 운영 연결
- 기존 Supabase 프로젝트에 `supabase/schema.sql`이 적용되어 있어야 한다.
- 추가로 `supabase/work-items.sql`을 적용한다. 기존 데이터를 삭제하지 않는다.
- 기존 Google OAuth와 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, ADMIN_USER_ID 설정이 필요하다.
- 비밀값은 GitHub나 대화에 입력하지 않고 서비스 설정 화면에서 관리한다.
- 기존 사용자 UUID/Google provider 검사와 동일 출처 쓰기 검사를 사용한다.
- 테이블은 RLS를 활성화하고 anon/authenticated 역할의 직접 조회를 차단한다.
- 동시 수정은 updated_at 비교로 충돌을 거절한다. 이미지 서명 실패가 이미 완료된 저장을 실패로 보고하지 않도록 처리한다.

## 확인 상태
2026-10-11 통합 전 운영 `/admin`에는 관리자 연결 준비 안내가 표시되었다. Vercel 설정 화면에는 필수 변수 이름이 Production/Preview 대상으로 등록되어 있으나 저장된 비밀값은 확인하지 않았다. 이름이 등록된 것만으로 런타임 설정이 유효하다고 판단하지 않는다.

실제 Google 로그인 왕복, DB 마이그레이션, 기기 간 저장 확인은 연결 완료 후 검증해야 한다. 공유 썸네일 관리 기능은 각 외부 사이트의 Open Graph 이미지를 자동 변경하지 않는다.

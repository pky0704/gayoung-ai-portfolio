# v1.0 이후 합의한 개발 범위

- 관리자 화면을 초기 범위에 포함: 추가·수정·이미지 교체·순서·임시저장·공개·비공개·휴지통 복구.
- 배포는 Vercel, 코드 저장소는 사용자 소유 GitHub, 데이터·이미지·Google 인증은 Supabase.
- 디자인은 밝은 A안, 오렌지 #FF6600, 절제된 타이포그래피. 실제 캡처 바로 위에 별도 커버.
- 페이지 전체 가로 스크롤 금지. 본문 16px 이상을 기본으로 적용.
- 관리자 계정은 비공개 배포 설정으로 연결. 공개 저장소에 이메일이나 키를 포함하지 않음.
- 기존 A안 원본 미확보: PRD 기반 재구성이라는 한계를 검수 시 명시.
- 공유용 별도 생성 이미지는 미제작. 현재는 제목·설명 메타데이터를 적용.

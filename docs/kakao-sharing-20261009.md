# 카카오톡 공유·외부 브라우저 안내 (2026-10-09)

대상: 가영이네 AI 장사기록
주소: https://gayoungai.vercel.app

포트폴리오에서 사이트 열기로 공개된 현재 버전만 변경했습니다.

- 카카오톡에서만 시작 전에 외부 브라우저 안내와 확인창을 표시합니다.
- 외부 열기는 사용자 클릭으로만 `kakaotalk://web/openExternal`을 시도합니다. 공개 보장 API가 아니므로 성공을 단정하지 않습니다.
- 취소하면 안내 화면에 머무릅니다. 주소 복사와 자동 복사 실패 시 직접 선택·복사를 제공합니다. Safari 등 사용자의 브라우저를 안내하며 Chrome을 강제하지 않습니다.
- 현재 경로·질의·해시를 유지합니다. 일반 브라우저와 공유 스크랩 로봇에는 안내를 표시하지 않습니다.
- 안내는 최소 16px, 버튼은 52px 이상, 좁은 화면 줄바꿈과 safe-area를 적용했습니다.
- 공유 썸네일: share-kakao-20261009.png (1734×907). 제목·설명·이미지는 서버 HTML 또는 정적 HTML 메타데이터에 연결했습니다.
- 공식 로고·실제 메뉴 사진·가격·고객 데이터·외부 알림은 변경하지 않았습니다.

## 검증
공통 JS는 메뉴 저장소 `node --test tests/sharing-guard.test.cjs` 11개 검사를 통과한 동일 파일입니다. 일반 브라우저/스크랩 로봇 제외, iPhone/Android 분기, 자동 앱 이동 없음, 취소, 클릭 후 이동 시도, 링크 유지, 복사 성공/실패, dialog 미지원, 영어 안내, 중복 실행을 검사했습니다. 이는 jsdom 코드 검사이며 iOS Safari/WebKit 또는 실제 카카오톡 검사가 아닙니다.

포트폴리오는 TypeScript·기존 4개 테스트·Next 빌드를, 선결제는 기존 33개 테스트를, 메뉴는 기존 데이터 12개와 7개 언어 DOM 검사를 통과했습니다. 음성/리뷰는 기존 빌드를 통과했고 리뷰는 렌더 HTML 검사를 통과했습니다.

## 남은 실기기 확인
실제 iPhone의 Safari 및 카카오톡에서 새 링크로 첫 화면, 외부 열기, 취소 후 주소 복사, 주요 입력/버튼, 키보드 표시·회전·가로 넘침을 확인해야 합니다. 이 실행 환경은 아이폰 실기기와 카카오톡 앱을 제공하지 않습니다. 음성 녹음·변환과 실제 고객 신청/결제/알림 발송은 실행하지 않았습니다.

이미 전송된 카카오톡 카드의 즉시 갱신은 보장하지 않습니다. 필요하면 카카오 공유 캐시를 갱신한 뒤 새 메시지로 다시 확인합니다.
